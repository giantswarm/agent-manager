# kagent.api.v1alpha1 client stubs

`internal/kagent/gen` holds the Go stubs of the kagent `SessionService` (plus the `common` and
`runtime` messages it uses), the gRPC service agent-manager's session tools call through
agentgateway. They are generated by `buf` (protoc-gen-go, protoc-gen-go-grpc) from the protos
under `kagent/` here, which are verbatim copies of `proto/kagent/api/v1alpha1/` in
`giantswarm/kagent-upstream` at the commit below (tag `v1.3.1`); `buf.lock` pins the
`buf/validate` dependency to the same commit's lock.

The A2A v1 service (`lf.a2a.v1.A2AService`) is not generated: kagent serves it from the stubs
`github.com/a2aproject/a2a-go/v2/a2apb/v1` ships (its `buf.gen.yaml` maps `a2a.proto` to that
package), and agent-manager uses the same package at the version kagent's `go.mod` requires.

Do not edit the generated files. To move the pin, set `KAGENT_PROTO_COMMIT` in
`Makefile.custom.mk` and run `make generate-kagent` (needs `buf`, `protoc-gen-go` and
`protoc-gen-go-grpc` on the PATH); the target runs `goimports` over the output because the
repository formats every Go file with it.
